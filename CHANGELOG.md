# What's changed in 🎬 Projector plugin?

## [1.0.0] 2026-05-31
- Initial release.
- Commands to set a note's **type** — `Set type: Project` / `Area` / `Note`.
- Commands to set **status** — `Set status: Active` / `Working` / `Paused` / `Someday` / `Completed` / `Canceled`.
- Sets the `icon` and `icon-color` frontmatter to match the type + status combination; `Set type: Note` clears icon/color/status; "Active" removes the `status` field.
